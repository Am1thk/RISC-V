# RISC-V Minimal CPU

## Overview
This project implements a simple single-cycle RISC-V processor in Verilog HDL.

## Features
- Instruction Fetch
- Instruction Decode
- Arithmetic Operations
- Memory Access
- Register Write Back

## Technologies Used
- Verilog HDL
- Digital Logic Design
- Hardware Simulation

## Purpose
The aim of this project is to understand how a processor works internally by designing and simulating a basic RISC-V CPU.
